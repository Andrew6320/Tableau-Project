Overview

This project is an interactive dashboard analysing NYPD crime data. It provides insights into complaint trends, locations, and patterns using data visualisation techniques. The dashboard was designed as part of an analytical exercise to demonstrate data storytelling and visualisation skills.

Features

Crime Trend Analysis: Visualises complaint occurrences over time.

Geospatial Mapping: Displays crime locations on an interactive map.

Category Breakdown: Analyses crime by type, borough, and precinct.

Time-based Filtering: Allows users to filter by year, month, or specific timeframes.

Comparative Analytics: Enables comparisons between different categories and trends.
